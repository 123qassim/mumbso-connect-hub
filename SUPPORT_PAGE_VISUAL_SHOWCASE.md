## ❓ FAQ Section Preview

```
Q: Is my donation tax-deductible?
A: As a recognized student organization at Maseno 
   University, donations may be eligible for tax 
   deductions. Contact us for official documentation.

Q: Can I donate in installments?
A: Yes! You can make multiple smaller donations over 
   time. Each contribution matters and helps us plan 
   effectively.

Q: What happens if I donate anonymously?
A: Anonymous donations are welcome. We respect your 
   privacy while honoring your generosity through 
   annual impact reports.

Q: How will I receive donation confirmation?
A: Instant SMS for M-Pesa/Airtel, plus email receipt 
   with impact details.

Q: Can organizations donate larger amounts?
A: Absolutely! Organizations can discuss bulk donations 
   and partnerships. Contact our treasurer.

Q: What if I have other payment suggestions?
A: We're always open to feedback. Contact us to discuss 
   additional payment methods or custom arrangements.
```

## ✨ Key Interaction Features

### Copy-to-Clipboard
1. User clicks copy icon next to payment detail
2. Text copies to clipboard (silent)
3. Button changes to show "Copied!" text
4. After 2 seconds, reverts to copy icon
5. User can paste in their banking app

### Badge System
```
[Most Popular] ⭐ - Indicates primary recommendation
[Available]    ✓  - Method ready to use
[Coming Soon]  ⏳ - Feature in development
```

### Progress Bar Animation
```
On page load:
Width: 0% → Animation to target percentage
Duration: 300ms smooth transition
Color: Gradient from teal to blue
Visual feedback of fund allocation
```

### Form Fields Concept
```
Payment Details:
┌─────────────────────┐
│ Paybill: 522522     │ [COPY]
│ Account: MUMBSO     │ [COPY]
└─────────────────────┘

When copied:
[COPY] button changes to "Copied!"
Auto-resets after 2 seconds
```

## 🎯 User Journey Map

### Desktop Flow
```
1. User sees header
2. Clicks "Support Us" nav item
3. Page loads with hero + stats
4. Scrolls to donation methods
5. Selects preferred method (e.g., M-Pesa)
6. Reads step-by-step instructions
7. Copies payment details
8. Reviews fund usage section
9. Sees alternative ways to help
10. Reads FAQ for concerns
11. Clicks "Donate Now" or final CTA
```

### Mobile Flow
```
1. User opens hamburger menu
2. Taps "Support Us"
3. Page loads mobile-optimized
4. Scrolls single-column layout
5. Views donation cards stacked
6. Taps copy button (touch-friendly)
7. Follows large text instructions
8. Scrolls to fund usage
9. Views alternative options
10. Reads FAQ
11. Taps full-width donate button
```
