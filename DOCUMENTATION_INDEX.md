## 🚀 Quick Start

### View the Page
1. Navigate to `localhost:8080/support`
2. Or click "Support Us" in header menu
3. Page loads with full donation section

### Update Content
1. Open `src/pages/Support.tsx`
2. Edit data arrays:
   - `donationMethods` - Payment options
   - `fundUsage` - Fund allocation
   - `impactStats` - Impact numbers
   - FAQ section in JSX
3. Save and reload

### Customize Design
1. All colors use theme variables (no hardcoding)
2. Update theme in `src/index.css` for global changes
3. Tailwind classes for responsive design
4. Dark mode automatic via `.dark` class
