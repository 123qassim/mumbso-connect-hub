## 🎯 Quick Reference

### Common Color Usage

```
PRIMARY ACTION
Light: bg-primary text-primary-foreground
Dark: bg-primary text-primary-foreground

SECONDARY ACTION
Light: bg-secondary text-secondary-foreground
Dark: bg-secondary text-secondary-foreground

DESTRUCTIVE ACTION
Light: bg-error text-white
Dark: bg-error text-white

OUTLINE BUTTON
Light: border-2 border-primary text-primary bg-background
Dark: border-2 border-primary text-primary bg-background

CARD
Light: bg-card text-card-foreground border border-border
Dark: bg-card text-card-foreground border border-border

FORM INPUT
Light: bg-input text-input-foreground border border-input-border
Dark: bg-input text-input-foreground border border-input-border

SUCCESS MESSAGE
Light: bg-success-light border border-success text-text-primary
Dark: bg-success-light border border-success text-text-primary

LINK
Light: text-primary hover:text-primary/80
Dark: text-primary hover:text-primary/80

DISABLED ELEMENT
Light: text-text-disabled opacity-60
Dark: text-text-disabled opacity-60
```

## 🌗 Theme Switching Flow

```
User Clicks Theme Toggle
    ↓
ThemeProvider Updates Context
    ↓
.dark Class Added/Removed from <html>
    ↓
CSS Variables Cascade to New Values
    ↓
All Components Update Automatically
    ↓
0.3s Smooth Transition Applied
    ↓
Preference Saved to localStorage
```

## 📱 Responsive Considerations

The color system works seamlessly across all breakpoints:

```
Mobile (< 640px):
- Same color palette and contrast ratios
- Touch targets remain accessible
- Text sizes adjust but colors stay consistent

Tablet (640px - 1024px):
- Colors adapt proportionally
- Cards and layouts reflow
- Contrast ratios maintained

Desktop (> 1024px):
- Full color palette available
- Complex layouts supported
- All hover states working
```

## 🔄 Color Transitions

All color changes animate smoothly:

```css
Transition Duration: 0.3s
Easing: cubic-bezier(0.4, 0, 0.2, 1)
Property: all

Elements Affected:
- Background colors
- Text colors
- Border colors
- Shadow colors
- Button states
- Link colors
```

## ✨ Special Effects

### Gradients (Theme-Aware)
- Hero Gradient: Primary → Secondary
- Accent Gradient: Accent → Primary
- Subtle Gradient: Background variations

### Shadows (Dynamic)
- Shadows adjust opacity for theme visibility
- Card shadows use brand color
- Glow effects available for emphasis

### Focus States
- 2px ring with primary color
- 2px offset in light mode
- Same ring offset in dark mode
